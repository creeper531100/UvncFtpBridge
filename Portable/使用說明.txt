UltraVNC 機台工具 — WinSCP（傳檔）＋ UltraVNC Viewer（看畫面）可攜套件

先把整個 ZIP 解壓縮到可寫入的資料夾。本機只有兩個啟動檔，都會同時開 WinSCP 與 UltraVNC Viewer：

  Start-Direct.cmd       直連：本機就連得到機台時用。
  Start-FileTunnel.cmd   經 RDP 跳板：本機連不到機台、要透過跳板時用（會開 ft.exe）。

共通用法：
1. 雙擊其中一個啟動檔。會開一個命令視窗，並自動開好 WinSCP 與 UltraVNC Viewer。
2. WinSCP：在「新增站台」填機台 IP、VNC 埠（預設 5900）及 VNC 密碼後登入。FTP、使用者名稱 ultravnc、代理都已預設好，不用調整。站台設定存在 WinSCP\WinSCP.ini。
3. UltraVNC Viewer：連線方式已預選「Repeater」，在伺服器欄填機台 IP（例如 10.1.2.3；非 5900 埠寫 10.1.2.3::5901），按 Connect，再輸入 VNC 密碼。
4. 命令視窗開著就一直可用；關閉 WinSCP 或 Viewer 不影響。可以把 WinSCP\WinSCP.exe 與 UltraVNC\vncviewer.exe 釘選到工作列，之後直接從工作列開（命令視窗要先開著）。也可以在命令視窗按 W 再開 WinSCP、按 V 再開 Viewer。
5. 用完按 Q 或直接關閉命令視窗，全部一起結束。
同一份套件再雙擊一次啟動檔，不會重複起服務，只會再開一次 WinSCP 與 Viewer。

經 RDP 跳板（Start-FileTunnel.cmd）另外要做：
1. 用 mstsc 連這次要用的跳板。連線前在「顯示選項 → 本機資源 → 詳細資料」勾選本機 C 槽；如果已有 RDP 工作階段，請斷線後重連才會生效。啟動檔不會替你開 RDP。
2. 把 UvncFtpBridge.exe、ft.exe 與 Start-FileTunnel-Remote.cmd 複製到跳板的同一資料夾，雙擊 Start-FileTunnel-Remote.cmd，保持黑色視窗開著。跳板端不需要 PowerShell 或 .NET，Windows 7 也可用。若本機系統磁碟不是 C，從命令列給它磁碟代號，例如 Start-FileTunnel-Remote.cmd D；若 TEMP 位置被自訂，給完整的重新導向路徑。
3. 剛啟動時跳板端要十幾秒才會連上；這段期間在 Viewer 按 Connect 會自動等待（最多 30 秒）。WinSCP 若先登入失敗，等跳板端連上後再按一次。
跳板端不會自己結束：本機關閉後它會回到等待，下次本機重開啟動檔就自動接上，RDP 斷線重連後也會接回。不用時再關掉跳板端視窗。
一次只對應一個跳板；切換跳板時先關閉舊跳板端，再於新的跳板啟動。
資料檔只放在本機 %TEMP%\UvncFtpBridge\FileTunnel，結束時會嘗試清除。本機 File-Tunnel 只聽 127.0.0.1:1081，跳板不可用時會報錯，不會自動改成直連。

其他說明：
- 本機服務只聽 127.0.0.1：UltraVNC Repeater 用 5999 埠，WinSCP 橋接用系統分配的埠。
- 套件內的 Viewer 設定存在 UltraVNC\options.vnc，每次從啟動檔開都會重新預選 Repeater。若改用電腦已安裝的 UltraVNC Viewer，請自行選「Repeater」並填 127.0.0.1:5999。
- 啟動失敗時可查看 Logs\launcher.log。
- 機台需開啟 UltraVNC Server 與 File Transfer，並使用完整權限的 VNC 密碼。
- 套件不預存任何機台 IP 或密碼。

CLI 直接使用：
  UvncFtpBridge.exe --help
  UvncFtpBridge.exe ls 機台IP --json
  UvncFtpBridge.exe get 機台IP C:\MES\log.txt
